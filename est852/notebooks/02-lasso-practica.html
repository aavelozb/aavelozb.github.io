Lasso en la práctica: selección, estructura y variables mixtas

Solo requiere numpy y matplotlib. Tres bloques:

  1. Selección de características: recuperar 5 variables relevantes escondidas entre 30.
  2. Descubrimiento de estructura: grafos de dependencia condicional y causalidad de Granger.
  3. Variables mixtas: dummies, la colinealidad con el intercepto, y group lasso.

Todos los modelos son lineales en sus parámetros.

import numpy as np
import matplotlib.pyplot as plt

rng_global = np.random.default_rng(0)
plt.rcParams.update({"figure.figsize": (8, 3.2), "axes.spines.top": False,
                     "axes.spines.right": False})

def estandarizar(X):
    return (X - X.mean(0)) / X.std(0)

0. La herramienta: lasso por descenso de coordenadas

Lasso resuelve \[\hat{\boldsymbol{\phi}} = \arg\min_{\boldsymbol{\phi}} \tfrac{1}{2}\|\mathbf{y}-\mathbf{Z}\boldsymbol{\phi}\|^2 + \lambda \sum_j |\phi_j|.\]

La penalización \(|\phi_j|\) tiene una esquina en cero, así que no hay fórmula cerrada. El descenso por coordenadas optimiza un coeficiente a la vez; cada subproblema unidimensional tiene solución exacta: el operador soft-thresholding

\[\operatorname{soft}[a, \lambda] = \operatorname{sign}[a]\,\max(|a|-\lambda,\, 0),\]

que corre \(a\) hacia cero en \(\lambda\) y, si cruza el cero, lo deja exactamente en cero. De ahí vienen los ceros exactos de lasso.

def soft(a, lam):
    return np.sign(a) * np.maximum(np.abs(a) - lam, 0.0)

def lasso_cd(X, y, lam, n_iter=500, w0=None):
    '''Descenso por coordenadas para 0.5*||y - Xw||^2 + lam*||w||_1.'''
    n, d = X.shape
    w = np.zeros(d) if w0 is None else w0.copy()
    col_sq = (X**2).sum(0)
    r = y - X @ w
    for _ in range(n_iter):
        for j in range(d):
            r += X[:, j] * w[j]
            rho = X[:, j] @ r
            w[j] = soft(rho, lam) / col_sq[j]
            r -= X[:, j] * w[j]
    return w

# el operador, visto
a = np.linspace(-2.5, 2.5, 400)
lam = 0.5
fig, ax = plt.subplots(figsize=(4.5, 3))
ax.axvspan(-lam, lam, color="0.92")
ax.plot(a, a, "--", color="0.7", label="identidad (MCO)")
ax.plot(a, a / (1 + lam), color="#ff9500", label="ridge: $a/(1+\lambda)$")
ax.plot(a, soft(a, lam), color="#00a3c8", lw=2, label="lasso: soft$[a,\lambda]$")
ax.set_xlabel("$a$"); ax.set_ylabel(r"$\phi^*$"); ax.legend(frameon=False)
ax.set_title("La zona muerta $[-lambda,lambda]$ produce ceros exactos");

1. Selección de características

Experimento con verdad conocida: \(I=80\) observaciones, \(p=30\) regresores con correlación entre vecinos (\(\rho_{jk}=0.5^{|j-k|}\)). Solo 5 regresores son relevantes; los otros 25 tienen coeficiente exactamente cero.

I, P = 80, 30
IDX_TRUE = np.array([0, 3, 7, 12, 20])
BETA_TRUE = np.zeros(P)
BETA_TRUE[IDX_TRUE] = [3.0, -2.0, 1.5, 1.0, -1.0]

rng = np.random.default_rng(7)
idx = np.arange(P)
Sigma = 0.5 ** np.abs(idx[:, None] - idx[None, :])
X = rng.standard_normal((I, P)) @ np.linalg.cholesky(Sigma).T
y = X @ BETA_TRUE + 2.0 * rng.standard_normal(I)
X = estandarizar(X)
y = y - y.mean()
print("X:", X.shape, "| relevantes:", IDX_TRUE)

1.1 El camino de soluciones

Al bajar \(\lambda\) desde muy grande, los coeficientes se activan de a uno. El orden de entrada es un ranking de evidencia.

lams = np.geomspace(0.3, 300, 60)[::-1]   # de mayor a menor (warm start)
W = np.zeros((len(lams), P))
w = np.zeros(P)
for k, lam in enumerate(lams):
    w = lasso_cd(X, y, lam, n_iter=200, w0=w)
    W[k] = w

fig, ax = plt.subplots()
for j in range(P):
    if j in IDX_TRUE:
        ax.plot(lams, W[:, j], lw=2)
    else:
        ax.plot(lams, W[:, j], lw=0.7, color="0.75")
ax.set_xscale("log"); ax.invert_xaxis()
ax.set_xlabel(r"$\lambda$ (decreciente)"); ax.set_ylabel(r"$\phi_j$")
ax.set_title("Colores: las 5 relevantes.  Gris: las 25 irrelevantes");

1.2 Elegir \(\lambda\) por validación cruzada

k = 5
lams_cv = np.geomspace(0.3, 300, 40)[::-1]
orden = np.arange(I); np.random.default_rng(7).shuffle(orden)
pliegues = np.array_split(orden, k)
cv = np.zeros((k, len(lams_cv)))
for f, pl in enumerate(pliegues):
    m = np.ones(I, bool); m[pl] = False
    w = np.zeros(P)
    for j, lam in enumerate(lams_cv):
        w = lasso_cd(X[m], y[m], lam, n_iter=200, w0=w)
        cv[f, j] = np.mean((X[pl] @ w - y[pl]) ** 2)
ecm = cv.mean(0)
lam_star = lams_cv[np.argmin(ecm)]

fig, ax = plt.subplots(figsize=(5, 3))
ax.semilogx(lams_cv, ecm, "o-", color="#00a3c8", ms=3)
ax.axvline(lam_star, color="#c1121f", ls="--")
ax.invert_xaxis()
ax.set_xlabel(r"$\lambda$"); ax.set_ylabel("ECM de CV (5 pliegues)")
print(f"lambda* = {lam_star:.2f}")

1.3 Qué se recupera

En \(\lambda^*\) el soporte contiene las 5 relevantes, más algunos falsos positivos (vecinas correlacionadas), y los coeficientes quedan encogidos. Reajustar MCO sobre el soporte (el “lasso relajado”) corrige el encogimiento.

w_lasso = lasso_cd(X, y, lam_star, n_iter=800)
soporte = np.where(np.abs(w_lasso) > 1e-8)[0]
w_refit = np.zeros(P)
w_refit[soporte] = np.linalg.lstsq(X[:, soporte], y, rcond=None)[0]

print("soporte estimado:", soporte)
print("soporte verdadero:", IDX_TRUE)
vp = set(soporte) & set(IDX_TRUE)
print(f"verdaderos positivos: {len(vp)}/5 | falsos positivos: {len(set(soporte)-set(IDX_TRUE))}")

fig, ax = plt.subplots()
jj = np.arange(P)
ax.bar(jj - 0.2, w_lasso, width=0.4, color="#00a3c8", label="lasso")
ax.bar(jj + 0.2, w_refit, width=0.4, color="#ff9500", label="MCO sobre el soporte")
ax.plot(jj, BETA_TRUE, "k_", ms=10, mew=1.6, label="verdad")
ax.legend(frameon=False); ax.set_xlabel("regresor $j$"); ax.set_ylabel(r"$\phi_j$");

Advertencias (detalle en la clase): estandarizar antes de penalizar; entre regresores correlacionados lasso elige uno arbitrariamente; la selección es inestable entre muestras; y los p-values calculados después de seleccionar con los mismos datos no son válidos.

2. Descubrimiento de estructura

El coeficiente de un modelo predictivo no es un efecto causal. Lo que la sparsity sí permite estimar es estructura: quién se relaciona con quién, condicional en el resto.

2.1 Grafo de dependencias condicionales (lasso por nodo)

Para variables gaussianas, \(x_j\) y \(x_k\) son condicionalmente independientes dado el resto si y solo si el coeficiente de \(x_k\) en la regresión de \(x_j\) sobre todas las demás es cero. Con una regresión lasso por nodo se estima el grafo (Meinshausen & Bühlmann, 2006).

p = 8
aristas_verdad = [(0,1),(1,2),(2,3),(0,4),(4,5),(5,6),(6,7),(1,5)]
Theta = np.eye(p)
for a_, b_ in aristas_verdad:
    Theta[a_, b_] = Theta[b_, a_] = -0.32
Xg = np.random.default_rng(11).multivariate_normal(
    np.zeros(p), np.linalg.inv(Theta), size=400)
Xg = estandarizar(Xg)

lam = 0.18 * len(Xg)
A = np.zeros((p, p), bool)
for j in range(p):
    resto = [k for k in range(p) if k != j]
    w = lasso_cd(Xg[:, resto], Xg[:, j], lam, n_iter=300)
    for w_k, k in zip(w, resto):
        if abs(w_k) > 1e-8:
            A[j, k] = True
A = A | A.T   # regla OR

rec = {frozenset((a_, b_)) for a_ in range(p) for b_ in range(a_+1, p) if A[a_, b_]}
verdad = {frozenset(e) for e in aristas_verdad}
print(f"aristas verdaderas recuperadas: {len(rec & verdad)}/{len(verdad)}")
print(f"aristas espurias: {len(rec - verdad)}")
print("espurias:", [tuple(sorted(e)) for e in rec - verdad])

2.2 Causalidad de Granger con lasso-VAR

Con series de tiempo la dirección viene del reloj: el pasado predice al futuro. Se simula \(x_t = \mathbf{A}\,x_{t-1} + \varepsilon_t\) con \(\mathbf{A}\) sparse y se estima cada fila con lasso. “\(x_k\) Granger-causa a \(x_j\)” si \(\hat A_{jk} \neq 0\).

pv, T = 5, 300
Av = np.zeros((pv, pv))
Av[0,0]=0.6; Av[1,0]=0.5; Av[1,1]=0.3; Av[2,1]=0.5; Av[2,2]=0.3
Av[3,3]=0.5; Av[4,2]=-0.45; Av[4,4]=0.3
rngv = np.random.default_rng(3)
xs = np.zeros((T, pv))
for t in range(1, T):
    xs[t] = Av @ xs[t-1] + rngv.standard_normal(pv)
Xl, Yn = estandarizar(xs[:-1]), xs[1:]

A_hat = np.zeros((pv, pv))
for j in range(pv):
    A_hat[j] = lasso_cd(Xl, Yn[:, j] - Yn[:, j].mean(), 0.09 * T, n_iter=300)

fig, axes = plt.subplots(1, 2, figsize=(8, 3))
for ax, M, ttl in zip(axes, [Av, A_hat], ["A verdadera", "A estimada (lasso)"]):
    ax.imshow(np.abs(M), cmap="Blues", vmin=0, vmax=0.6)
    ax.set_title(ttl); ax.set_xlabel("predice ($t-1$)"); ax.set_ylabel("predicha ($t$)")
    for a_ in range(pv):
        for b_ in range(pv):
            if abs(M[a_, b_]) > 1e-8:
                ax.text(b_, a_, f"{M[a_, b_]:.2f}", ha="center", va="center",
                        fontsize=7, color="w" if abs(M[a_, b_]) > 0.3 else "0.2")

Advertencia causal: estos grafos son hipótesis de estructura, no efectos. Leerlos causalmente exige supuestos (sin confusores ocultos, linealidad; sin tiempo, las aristas no tienen dirección). Para estimar efectos de tratamiento con controles seleccionados por lasso, la receta correcta es la doble selección (Belloni, Chernozhukov & Hansen, 2014).

3. Variables mixtas: numéricas + categóricas

3.1 Codificación con dummies y la colinealidad con el intercepto

Una categórica de \(K\) niveles entra como columnas indicadoras. Si se usan las \(K\) columnas junto con el intercepto, las indicadoras suman 1 en cada fila y reproducen la columna del intercepto: colinealidad exacta, \(\mathbf{Z}^\top\mathbf{Z}\) singular.

rngc = np.random.default_rng(9)
region = rngc.integers(0, 3, 8)          # 3 niveles: 0=Norte, 1=Centro, 2=Sur

def onehot_completo(c, K):
    M = np.zeros((len(c), K))
    M[np.arange(len(c)), c] = 1
    return M

Z_K   = np.column_stack([np.ones(8), onehot_completo(region, 3)])   # intercepto + K
Z_Km1 = np.column_stack([np.ones(8), onehot_completo(region, 3)[:, 1:]])  # intercepto + K-1

print("intercepto + K columnas:   rango", np.linalg.matrix_rank(Z_K),
      "de", Z_K.shape[1], "-> singular")
print("intercepto + K-1 columnas: rango", np.linalg.matrix_rank(Z_Km1),
      "de", Z_Km1.shape[1], "-> invertible")

# con K columnas hay infinitas soluciones con las mismas predicciones:
yc = rngc.standard_normal(8)
w1 = np.linalg.pinv(Z_K) @ yc
w2 = w1 + np.array([1.0, -1.0, -1.0, -1.0])   # mover 1 del intercepto a los niveles
print("\nmismas predicciones con dos vectores distintos:",
      np.allclose(Z_K @ w1, Z_K @ w2))

3.2 Lasso vs. group lasso

Experimento con verdad conocida: dos numéricas (\(z_1\) relevante, \(z_2\) no) y dos categóricas de 4 niveles (A relevante, B no), codificadas con \(K-1=3\) dummies.

  • Lasso penaliza columna por columna: puede anular algunos niveles de A y conservar otros.
  • Group lasso penaliza la norma euclidiana de cada grupo, \(\lambda \sum_g \sqrt{p_g}\,\|\boldsymbol{\phi}_g\|_2\): el grupo completo entra o sale.
def group_lasso_pg(X, y, grupos, lam, n_iter=4000):
    '''Gradiente proximal: paso de gradiente + soft-thresholding por grupo.'''
    w = np.zeros(X.shape[1])
    alpha = 1.0 / np.linalg.eigvalsh(X.T @ X).max()
    for _ in range(n_iter):
        w = w - alpha * (X.T @ (X @ w - y))
        for g in grupos:
            ng = np.linalg.norm(w[g])
            umbral = alpha * lam * np.sqrt(len(g))
            w[g] = 0.0 if ng <= umbral else w[g] * (1 - umbral / ng)
    return w

rngm = np.random.default_rng(9)
Im = 150
z1 = rngm.standard_normal(Im); z2 = rngm.standard_normal(Im)
catA = rngm.integers(0, 4, Im); catB = rngm.integers(0, 4, Im)
efecto_A = np.array([2.0, 0.0, -1.5, 0.5])
ym = 1.5 * z1 + efecto_A[catA] + rngm.standard_normal(Im)

def dummies(c, K):     # K-1 columnas; nivel 0 = referencia
    M = np.zeros((len(c), K - 1))
    for k in range(1, K):
        M[:, k - 1] = (c == k)
    return M

Xm = estandarizar(np.column_stack([z1, z2, dummies(catA, 4), dummies(catB, 4)]))
ym = ym - ym.mean()
nombres = ["z1", "z2", "A2", "A3", "A4", "B2", "B3", "B4"]
grupos = [[0], [1], [2, 3, 4], [5, 6, 7]]

w_l = lasso_cd(Xm, ym, lam=50.0, n_iter=800)
w_g = group_lasso_pg(Xm, ym, grupos, lam=24.0)

fig, axes = plt.subplots(1, 2, figsize=(9, 3), sharey=True)
for ax, wv, ttl in zip(axes, [w_l, w_g],
                       ["lasso: niveles sueltos", "group lasso: grupos completos"]):
    ax.axvspan(1.5, 4.5, color="0.94"); ax.axvspan(4.5, 7.5, color="0.88")
    ax.bar(range(8), wv, color=["#00a3c8" if abs(v) > 1e-8 else "0.75" for v in wv])
    ax.set_xticks(range(8), nombres); ax.set_title(ttl); ax.axhline(0, color="0.8")
axes[0].set_ylabel(r"$\phi_j$")

print("lasso      :", " ".join(f"{v:6.2f}" for v in w_l))
print("group lasso:", " ".join(f"{v:6.2f}" for v in w_g))
print("\nlasso anula el nivel A4 (grupo A incompleto);")
print("group lasso conserva A completo y elimina z2 y B completos.")
