Probabilistic Graphical Models, exact inference from scratch

This notebook implements a small Bayesian Network without using a specialized PGM library.

We use the job-interview example from the course material:

  • Experience and Grades influence Interview.
  • Grades influences Admission.
  • Interview influences Offer.

The goal is to see how CPDs define a joint distribution and how probabilistic queries can be computed.

2. Define the CPDs

We encode the same CPDs used in the reference notebook. Variables are discrete:

  • Experience: 0 = low, 1 = high
  • Grades: 0 = low, 1 = high
  • Interview: 0 = poor, 1 = okay, 2 = excellent
  • Admission: 0 = no, 1 = yes
  • Offer: 0 = no, 1 = yes
domains = {
    "Experience": [0, 1],
    "Grades": [0, 1],
    "Interview": [0, 1, 2],
    "Admission": [0, 1],
    "Offer": [0, 1],
}

parents = {
    "Experience": [],
    "Grades": [],
    "Interview": ["Experience", "Grades"],
    "Admission": ["Grades"],
    "Offer": ["Interview"],
}

cpd = {
    "Experience": {(): {0: 0.6, 1: 0.4}},
    "Grades": {(): {0: 0.7, 1: 0.3}},
    "Interview": {
        (0, 0): {0: 0.8, 1: 0.18, 2: 0.02},
        (0, 1): {0: 0.3, 1: 0.6, 2: 0.1},
        (1, 0): {0: 0.3, 1: 0.4, 2: 0.3},
        (1, 1): {0: 0.1, 1: 0.2, 2: 0.7},
    },
    "Admission": {
        (0,): {0: 0.7, 1: 0.3},
        (1,): {0: 0.2, 1: 0.8},
    },
    "Offer": {
        (0,): {0: 0.9, 1: 0.1},
        (1,): {0: 0.4, 1: 0.6},
        (2,): {0: 0.01, 1: 0.99},
    },
}

variables = ["Experience", "Grades", "Interview", "Admission", "Offer"]

3. Joint probability by factorization

The Bayesian Network defines:

\[ p(E,G,I,A,O)=p(E)p(G)p(I\mid E,G)p(A\mid G)p(O\mid I). \]

def local_prob(var, value, assignment):
    parent_values = tuple(assignment[p] for p in parents[var])
    return cpd[var][parent_values][value]


def joint_prob(assignment):
    prob = 1.0
    for var in variables:
        prob *= local_prob(var, assignment[var], assignment)
    return prob


def all_assignments(vars_to_enumerate):
    for values in itertools.product(*[domains[v] for v in vars_to_enumerate]):
        yield dict(zip(vars_to_enumerate, values))


total = sum(joint_prob(a) for a in all_assignments(variables))
print(f"Total probability over all states: {total:.6f}")
Total probability over all states: 1.000000

4. Query by enumeration

For a query such as \(P(Offer=1\mid Grades=0)\), we sum all joint states compatible with the query and evidence, then normalize.

def matches(assignment, constraints):
    return all(assignment[k] == v for k, v in constraints.items())


def probability(event, evidence=None):
    evidence = evidence or {}
    numerator = 0.0
    denominator = 0.0
    for assignment in all_assignments(variables):
        p = joint_prob(assignment)
        if matches(assignment, evidence):
            denominator += p
            if matches(assignment, event):
                numerator += p
    return numerator / denominator


queries = [
    ({"Offer": 1}, {}),
    ({"Offer": 1}, {"Grades": 0}),
    ({"Offer": 1}, {"Grades": 0, "Experience": 0}),
]

for event, evidence in queries:
    print(f"P({event} | {evidence}) = {probability(event, evidence):.3f}")
P({'Offer': 1} | {}) = 0.433
P({'Offer': 1} | {'Grades': 0}) = 0.351
P({'Offer': 1} | {'Grades': 0, 'Experience': 0}) = 0.208

5. Causal, evidential, and intercausal reasoning

  • Causal reasoning: from cause to effect.
  • Evidential reasoning: from effect to cause.
  • Intercausal reasoning: between causes of a common effect, also called explaining away.

6. A small variable-elimination calculation

Suppose the query is \(P(Offer\mid Grades=0)\).

The full enumeration sums over Experience, Interview, and Admission. But Admission is irrelevant to Offer once we only condition on Grades, because

\[ \sum_a p(a\mid g)=1. \]

So we can eliminate it immediately.

def offer_given_grade_by_elimination(g):
    unnormalized = {}
    for o in domains["Offer"]:
        total = 0.0
        for i in domains["Interview"]:
            # Inner factor after summing out Experience.
            msg_experience_to_interview = 0.0
            for e in domains["Experience"]:
                msg_experience_to_interview += cpd["Experience"][()][e] * cpd["Interview"][(e, g)][i]
            total += cpd["Offer"][(i,)][o] * msg_experience_to_interview
        unnormalized[o] = cpd["Grades"][()][g] * total
    z = sum(unnormalized.values())
    return {o: p / z for o, p in unnormalized.items()}


dist = offer_given_grade_by_elimination(g=0)
print(dist)
print("P(Offer=1 | Grades=0) by VE =", round(dist[1], 3))
print("P(Offer=1 | Grades=0) by enumeration =", round(probability({"Offer": 1}, {"Grades": 0}), 3))

7. Parameter learning by counting

If the graph structure is known and data are complete, maximum-likelihood estimation decomposes by CPD:

\[ \hat p(x_i\mid pa_i)=\frac{N(x_i,pa_i)}{N(pa_i)}. \]

The next cell generates samples from the network and estimates one CPD.

rng = np.random.default_rng(0)

def sample_from_dist(dist):
    values = list(dist.keys())
    probs = np.array([dist[v] for v in values])
    return rng.choice(values, p=probs)


def sample_bn(n=5000):
    rows = []
    for _ in range(n):
        a = {}
        for var in variables:
            parent_values = tuple(a[p] for p in parents[var])
            a[var] = sample_from_dist(cpd[var][parent_values])
        rows.append(a)
    return rows


samples = sample_bn()

# Estimate P(Offer | Interview)
for interview_value in domains["Interview"]:
    rows = [r for r in samples if r["Interview"] == interview_value]
    estimate = np.mean([r["Offer"] == 1 for r in rows])
    truth = cpd["Offer"][(interview_value,)][1]
    print(f"P(Offer=1 | Interview={interview_value}): estimate={estimate:.3f}, true={truth:.3f}")
