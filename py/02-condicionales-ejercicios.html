1.1 Ejercicio 1 — Preguntas breves (instrucción por pares)

a) ¿Cuál es el resultado de la expresión (5 > 3) and (10 < 5)?

    a) True    b) False    c) None

b) Si x = 10 e y = 20, ¿cuál es el resultado de x < y?

    a) True    b) False    c) 10

c) ¿Cuál de las siguientes opciones define correctamente un condicional en Python?

    a) if condicion: print("True")     b) if (condicion) { print("True") }     c) if condicion: { print("True") }     d) if condicion then: print("True")

d) Para comprobar si un número es positivo o negativo, ¿qué tipo de condicional usaríamos?

    a) if    b) if-else    c) if-elif-else    d) Ninguno, basta una expresión lógica.

e) Dadas a, b y c, ¿cuál imprime "Es válido" si a es mayor que b o c es menor que a?

    a) if a > b or c < a: print("Es válido")     b) if a > b and c < a: print("Es válido")     c) if a > b and a < c: print("Es válido")     d) if a > b or a < c: print("Es válido")

f) ¿Cuál es el resultado de True and not False or False?

    a) True    b) False    c) None

NotaRespuestas

a) b) False. (5 > 3) es True, pero (10 < 5) es False, y and exige que ambos sean verdaderos.

b) a) True.

c) a) Python usa : e indentación; las llaves {} y la palabra then no existen en Python.

d) b) if-else: son dos caminos excluyentes.

e) a) El enunciado dice “a mayor que b” (a > b) o “c menor que a” (c < a).

f) a) True. Precedencia: not > and > or, así que se lee (True and (not False)) or False = True or False = True.

1.2 Ejercicio 2 — De lenguaje natural a operadores lógicos

Escribe la condición lógica que modela cada frase e indica cuándo resulta True y cuándo False:

a) “Iré en bicicleta a comprar si no está lloviendo y si el negocio está a menos de 5 km.”

b) “Hago deporte si es martes o jueves.”

NotaSolución

a) Con lloviendo (bool) y distancia (número, en km):

voy_en_bici = (not lloviendo) and (distancia < 5)

Es True solo si se cumplen las dos cosas a la vez: no llueve y el negocio está a menos de 5 km. Es False si llueve, o si el negocio está a 5 km o más (o ambas).

b) Con dia (string):

hago_deporte = (dia == 'martes') or (dia == 'jueves')

Es True si el día es martes, o si es jueves. Es False los otros cinco días.

Error frecuente: escribir dia == 'martes' or 'jueves'. Python lo evalúa como (dia == 'martes') or ('jueves'), y como el string 'jueves' no está vacío, ¡la condición es siempre verdadera!

1.3 Ejercicio 3 — Leyes de De Morgan

a) Para ser presidente de Chile se debe ser chileno por nacimiento y mayor de 35 años. ¿Bajo qué condiciones no se puede ser presidente de Chile?

b) Dejo de comer cuando ya no tengo comida en el plato o cuando no tengo hambre. ¿En qué circunstancias sigo comiendo?

TipPista

\[\text{not}(A \text{ and } B) \equiv (\text{not } A) \text{ or } (\text{not } B)\] \[\text{not}(A \text{ or } B) \equiv (\text{not } A) \text{ and } (\text{not } B)\]

La negación da vuelta el operador: and se convierte en or y viceversa.

NotaSolución

a) Puede ser presidente: chileno_por_nacimiento and edad > 35.

not (chileno and edad > 35)  ==  (not chileno) or (edad <= 35)

No se puede ser presidente si no se es chileno por nacimiento, o si se tiene 35 años o menos. Basta que falle una de las dos condiciones.

b) Dejo de comer: plato_vacio or (not hambre).

not (plato_vacio or not hambre)  ==  (not plato_vacio) and hambre

Sigo comiendo mientras queda comida en el plato Y además tengo hambre. Deben cumplirse las dos.

1.4 Ejercicio 4 — Condición de año bisiesto

“Un año es bisiesto si es divisible por 4, con excepción de los que son divisibles por 100 y no por 400.”

Escribe la expresión lógica es_bisiesto (todavía no un programa completo) que sea verdadera si el año es bisiesto.

TipPista

Traduce cada trozo por separado:

  • “divisible por 4” → anio % 4 == 0
  • “con excepción de” → and not (...)
  • “divisible por 100 y no por 400” → anio % 100 == 0 and anio % 400 != 0
Solución 
anio = int(input('Ingrese año: '))

# Traducción literal del enunciado
es_bisiesto = (anio % 4 == 0) and not (anio % 100 == 0 and anio % 400 != 0)

# Forma equivalente (aplicando De Morgan a la excepción)
es_bisiesto = (anio % 4 == 0 and anio % 100 != 0) or (anio % 400 == 0)

print(es_bisiesto)
NotaComentario

Ambas expresiones son equivalentes. La segunda se obtiene de la primera aplicando De Morgan:

not (A and B) = (not A) or (not B), con A = anio % 100 == 0 y B = anio % 400 != 0, y luego distribuyendo el and.

Comprobación rápida: 2024 → True; 1900 → False (divisible por 100 y no por 400); 2000 → True (divisible por 400); 2023 → False.

1.5 Ejercicio 5 — Especificar una condición compuesta

Escribe una condición lógica para la siguiente frase:

“Yo tengo horas de atención a estudiantes los lunes y los miércoles, siempre que no sea feriado, pero por superstición también atiendo todos los martes 13.”

Supón que dispones de las variables dia ('lunes', 'martes', …), fecha (día del mes, entero) y feriado (booleano).

TipPista

El operador principal es un or: hay dos formas independientes de que haya atención. Escribe primero cada una por separado y recién después únelas.

Solución 
dia = input('Día: ')
fecha = int(input('Día del mes: '))
feriado = input('¿Es feriado? (s/n): ') == 's'

regla_normal   = (dia == 'lunes' or dia == 'miercoles') and not feriado
regla_martes13 = (dia == 'martes' and fecha == 13)

atiende = regla_normal or regla_martes13

print(atiende)
NotaComentario

La condición completa es:

atiende = ((dia == 'lunes' or dia == 'miercoles') and not feriado) or (dia == 'martes' and fecha == 13)

Dos detalles importantes:

  1. Los paréntesis alrededor de (dia == 'lunes' or dia == 'miercoles') son imprescindibles: sin ellos, and se evalúa antes que or y el not feriado quedaría aplicándose solo al miércoles.
  2. La excepción del martes 13 va fuera del not feriado: se atiende “todos los martes 13”, sea feriado o no.

2.1 Ejercicio 6 — ¿Cuántas veces se ejecuta?

n = int(input())
if n < 0:
    n = abs(n)
print(n)

Se ejecuta el programa 10 veces distintas, con estas entradas:

5   -2   0   0   -3   -1   7   0   2   -2

a) ¿Cuántas veces en total se ejecuta la instrucción n = abs(n)?

b) En el mismo escenario, ¿cuántas veces se ejecuta print(n)?

NotaSolución

a) 4 veces. Solo cuando la entrada es negativa: -2, -3, -1, -2.

b) 10 veces. print(n) está fuera del if (sin indentar), así que se ejecuta siempre, en las 10 ejecuciones.

La idea que hay que instalar: la indentación decide qué instrucciones son parte del if y cuáles son parte del programa principal. El 0 no es negativo, así que no entra al if.

2.2 Ejercicio 7 — Determinar la salida

Considerando el siguiente código, determina la salida para las entradas a) 2022, b) 4000, c) 1999.

a = int(input("Ingrese dato: "))
if a % 4 == 0:
    if a % 100 == 0 and a % 400 != 0:
        print("No es")
    else:
        print("Lo es")
else:
    print("No es")
NotaSolución
Entrada a % 4 == 0 a % 100 == 0 a % 400 != 0 Salida
2022 False (2022 % 4 = 2) — — No es
4000 True True False (4000 % 400 = 0) Lo es
1999 False (1999 % 4 = 3) — — No es

Es el mismo criterio del ejercicio 4, pero escrito con if anidados en vez de una sola expresión lógica. Vale la pena hacer notar que el else interno está asociado al if interno, y el externo al externo: lo determina la indentación.

2.3 Ejercicio 8 — if-elif vs. if sueltos

a) El siguiente programa determina el nivel de estudios de una persona a partir de su edad:

if edad < 6:
    print('Preescolar')
elif edad < 18:
    print('Escolar')
elif edad < 25:
    print('Universitario')
else:
    print('Postgrado')

¿Qué condición debe cumplirse para que imprima Escolar? ¿Y para que llegue al último else?

b) Un programador hizo esta otra implementación del mismo problema:

if edad < 6:
    print('Preescolar')
if edad < 18:
    print('Escolar')
if edad < 25:
    print('Universitario')
else:
    print('Postgrado')

¿Qué problemas tiene? Da un ejemplo.

c) Se propone la siguiente mejora:

if edad < 6:
    print('Preescolar')
if 6 <= edad < 18:
    print('Escolar')
if 18 <= edad < 25:
    print('Universitario')
else:
    print('Postgrado')

¿Está correcta? Justifica.

NotaSolución

a) Para imprimir Escolar se necesita edad >= 6 and edad < 18. Aunque en el código escrito solo aparece edad < 18, el elif arrastra la negación de todas las condiciones anteriores: para llegar ahí, edad < 6 tuvo que ser False.

Para llegar al último else: edad >= 25.

b) Al usar if sueltos, todas las condiciones se evalúan de forma independiente y se pueden imprimir varias líneas. Con edad = 3:

Preescolar
Escolar
Universitario

Además el else está asociado solo al último if (edad < 25), no a la cadena completa: con edad = 3 no se imprime Postgrado, pero con edad = 30 se imprime Postgrado (que es lo correcto, por casualidad).

c) No, sigue estando mal. Los rangos ya no se solapan, así que el problema de las impresiones múltiples se resolvió, pero el else sigue colgando del último if. Entonces, para edad = 3:

Preescolar
Postgrado

porque 18 <= 3 < 25 es False y se ejecuta su else. Lo mismo pasa con edad = 10 (Escolar + Postgrado).

La única forma correcta con if sueltos es escribir explícitamente la cuarta condición:

if edad >= 25:
    print('Postgrado')

Moraleja: cuando las alternativas son mutuamente excluyentes, if-elif-else no es solo más corto: es más difícil de equivocar.

2.4 Ejercicio 9 — Ruteo: ¿es correcta la fecha?

El siguiente programa determina si una fecha es correcta, considerando un rango de años válido, la cantidad de días de cada mes y los años bisiestos para el caso de febrero.

dd   = int(input('Ingrese día: '))
mm   = int(input('Ingrese mes: '))
aaaa = int(input('Ingrese año: '))

esBisiesto = (aaaa % 4 == 0)
esBisiesto = esBisiesto and (aaaa % 100 != 0 or aaaa % 400 == 0)

anioOk = aaaa >= 1800
mesOk  = (mm > 0 and mm <= 12)
diaOk  = (dd > 0 and dd <= 31)

if mm == 4 or mm == 6 or mm == 9 or mm == 11:
    diaOk = diaOk and (dd <= 30)

if mm == 2:
    if esBisiesto:
        diaOk = diaOk and (dd <= 29)
    else:
        diaOk = diaOk and (dd <= 28)

if anioOk and mesOk and diaOk:
    print('Fecha correcta')
else:
    print('Fecha incorrecta')

Completa la tabla de ruteo para las entradas a) 29 2 2020, b) 31 6 2020, c) 31 7 2020.

dd mm aaaa esBisiesto anioOk mesOk diaOk Salida
a)
b)
c)
NotaSolución (tabla de ruteo)
dd mm aaaa esBisiesto anioOk mesOk diaOk Salida
a) 29 2 2020 True True True True → True Fecha correcta
b) 31 6 2020 True True True True → False Fecha incorrecta
c) 31 7 2020 True True True True Fecha correcta

Detalle del ruteo de diaOk, que es la variable interesante porque se va actualizando:

  • a) parte en True (29 está entre 1 y 31). mm == 2, y como 2020 es bisiesto: diaOk = True and (29 <= 29) → True.
  • b) parte en True (31 está entre 1 y 31). Junio está en la lista de meses de 30 días: diaOk = True and (31 <= 30) → False.
  • c) parte en True. Julio no está en la lista de 30 días ni es febrero: diaOk queda True.

Nota sobre esBisiesto: se construye en dos pasos, acumulando sobre sí misma. Es la misma expresión del ejercicio 4, partida en dos líneas para que se lea mejor.

3.1 Ejercicio 10 — Clasificador de sismos

Después de obtener tu título, iniciaste tu carrera laboral en el Centro Sismológico Nacional. En tu primer día tu jefe te encomienda implementar un clasificador de sismos:

Magnitud Descripción
0.0 – 1.9 Menor
2.0 – 4.9 Moderado
5.0 + Fuerte

Desarrolla un programa capaz de clasificar los sismos. Observa los ejemplos para definir correctamente los condicionales (ojo con el último):

Ingrese el grado del sismo: 0.1
El sismo es Menor
Ingrese el grado del sismo: 10.9
El sismo es Fuerte
Ingrese el grado del sismo: -10
Valor no válido para la magnitud
TipPista

Hay cuatro casos, no tres: el enunciado no dice nada sobre magnitudes negativas, pero el tercer ejemplo sí. ¿Conviene validar primero o al final?

Solución 
grado = float(input("Ingrese el grado del sismo: "))

if grado < 0:
    print("Valor no válido para la magnitud")
elif grado < 2.0:
    print("El sismo es Menor")
elif grado < 5.0:
    print("El sismo es Moderado")
else:
    print("El sismo es Fuerte")
NotaComentario

Poner la validación primero es lo que permite que el resto de la cascada quede simple: cuando llegamos a elif grado < 2.0 ya sabemos que grado >= 0.

Fíjate además en que el corte se escribe < 2.0 y no <= 1.9: la magnitud es un float, y 1.95 debe clasificarse como Menor. Escribir <= 1.9 dejaría un hueco entre 1.9 y 2.0.

3.2 Ejercicio 11 — Capibaras y mandarinas

Eres parte del equipo encargado de la sección de capibaras del zoológico de tu ciudad. A los capibaras les encanta relajarse en agua con mandarinas en sus cabezas, así que tu trabajo consiste en distribuir las mandarinas entre los capibaras.

Desarrolla un programa que reciba la cantidad de mandarinas disponibles y la cantidad total de capibaras. Las reglas son:

  1. Cada capibara requiere exactamente 3 mandarinas.
  2. Debes revisar primero la cantidad de mandarinas que tienes:
    • Si tienes menos mandarinas que las que necesitas, debes volver a la bodega a buscar más.
    • Si tienes tantas mandarinas como las que necesitas, ya las puedes repartir.
    • Si tienes más mandarinas que las que necesitas, debes devolver lo que sobra a la bodega.
Ingrese la cantidad de mandarinas: 3
Ingrese la cantidad de capibaras: 4
Faltan mandarinas! Tienes que ir a buscar mas a la bodega.
Ingrese la cantidad de mandarinas: 9
Ingrese la cantidad de capibaras: 3
Muy bien, puedes repartir las mandarinas.
Ingrese la cantidad de mandarinas: 10
Ingrese la cantidad de capibaras: 3
Sobran mandarinas! Tienes que devolverlas a la bodega.
Solución 
mandarinas = int(input("Ingrese la cantidad de mandarinas: "))
capibaras  = int(input("Ingrese la cantidad de capibaras: "))

necesarias = 3 * capibaras

if mandarinas < necesarias:
    print("Faltan mandarinas! Tienes que ir a buscar mas a la bodega.")
elif mandarinas == necesarias:
    print("Muy bien, puedes repartir las mandarinas.")
else:
    print("Sobran mandarinas! Tienes que devolverlas a la bodega.")
NotaComentario

La clave es calcular primero necesarias = 3 * capibaras y recién después decidir. Meter la multiplicación dentro de cada condición funciona, pero repite la misma cuenta tres veces.

Comparar tres alternativas mutuamente excluyentes (<, ==, >) es el caso de libro para if-elif-else: la tercera rama no necesita condición, porque si no es menor ni igual, es mayor.

3.3 Ejercicio 12 — Solución de \(ax + b = 0\)

Escribe un programa que reciba como entrada \(a\) y \(b\), y entregue la solución de la ecuación \(ax + b = 0\). Debe validarse si la ecuación tiene solución, es decir, si \(a \neq 0\).

TipPista

¿Qué pasa cuando a == 0? Hay en realidad dos subcasos distintos, según el valor de b.

Solución 
a = float(input('Ingrese a: '))
b = float(input('Ingrese b: '))

if a != 0:
    x = -b / a
    print('La solución es x =', x)
else:
    print('La ecuación no tiene solución única.')
NotaComentario

La versión mínima que pide el enunciado es la de arriba. Ahora bien, cuando a == 0 la ecuación queda b = 0, y ahí hay dos situaciones distintas que vale la pena distinguir en clase:

if a != 0:
    print('La solución es x =', -b / a)
elif b == 0:
    print('Infinitas soluciones: cualquier x sirve.')
else:
    print('No hay solución.')

Lo importante: la validación a != 0 va antes de la división. Si se invierte el orden, el programa se cae con ZeroDivisionError antes de alcanzar a decidir.

3.4 Ejercicio 13 — El mayor de tres números

Determina el mayor de 3 números enteros ingresados como entrada. Resuélvelo de dos maneras: con instrucciones if anidadas, y con condiciones complejas basadas en and / or.

Ejemplos:

  • Si se ingresa 3, 1, 2 en cualquier orden, debe mostrar 3.
  • Si se ingresa 1, 1, 2 en cualquier orden, debe mostrar 2.
  • Si se ingresa 1, 1, 1, debe mostrar 1.
TipPista

En la versión con condiciones complejas, cuidado con los empates: si usas > estricto, el caso 1, 1, 1 no entra en ninguna rama. Usa >=.

Solución 1 — if anidados 
a = int(input('a: '))
b = int(input('b: '))
c = int(input('c: '))

# --- Versión 1: if anidados ---------------------------------
if a >= b:
    if a >= c:
        mayor = a
    else:
        mayor = c
else:
    if b >= c:
        mayor = b
    else:
        mayor = c

print('El mayor es', mayor)
Solución 2 — condiciones complejas 
a = int(input('a: '))
b = int(input('b: '))
c = int(input('c: '))

# --- Versión 2: condiciones complejas -----------------------
if a >= b and a >= c:
    mayor = a
elif b >= a and b >= c:
    mayor = b
else:
    mayor = c

print('El mayor es', mayor)
NotaComentario

Con 1, 1, 1 la versión 2 entra en la primera rama (1 >= 1 and 1 >= 1 es True) y responde 1. Si se hubiera escrito con > estricto, ninguna de las tres condiciones se cumpliría en el caso de triple empate.

Un tercer camino, útil para mostrar la idea de “acumulador”:

mayor = a
if b > mayor:
    mayor = b
if c > mayor:
    mayor = c

Este es el patrón que reaparecerá en la unidad de ciclos, cuando los números no sean tres sino \(n\).

3.5 Ejercicio 14 — Punto y circunferencia

Dado un círculo (coordenadas del centro y radio) y un punto cualquiera (coordenadas), determina si el punto está dentro, fuera o justo en la circunferencia del círculo.

TipPista

La distancia entre \((x_0, y_0)\) y \((x, y)\) es

\[d = \sqrt{(x - x_0)^2 + (y - y_0)^2}\]

Compara d con el radio. Para evitar la raíz, también puedes comparar \(d^2\) con \(r^2\).

Solución 
from math import sqrt

x0 = float(input('x del centro: '))
y0 = float(input('y del centro: '))
r  = float(input('radio: '))
x  = float(input('x del punto: '))
y  = float(input('y del punto: '))

d = sqrt((x - x0)**2 + (y - y0)**2)

if d < r:
    print('El punto está DENTRO del círculo.')
elif d > r:
    print('El punto está FUERA del círculo.')
else:
    print('El punto está JUSTO EN la circunferencia.')
NotaComentario

Sin math, la raíz también se puede escribir como d = ((x-x0)**2 + (y-y0)**2) ** 0.5.

Sobre el caso “justo en la circunferencia”: con float la igualdad exacta casi nunca se cumple en la práctica (por el redondeo binario). Si quieres ser riguroso, se compara con una tolerancia:

if abs(d - r) < 1e-9:
    print('El punto está JUSTO EN la circunferencia.')

Para efectos de esta unidad basta la versión con == implícito del else, pero es una buena conversación de clase.

4 Bloque 4 — Condiciones compuestas y validación

Problemas donde la dificultad ya no está en el if, sino en escribir bien la condición.

4.1 Ejercicio 15 — Tipo de triángulo según sus lados

Los tres lados \(a\), \(b\) y \(c\) de un triángulo deben satisfacer la desigualdad triangular: cada uno de los lados no puede ser más largo que la suma de los otros dos.

Escribe un programa que reciba como entrada los tres lados de un triángulo, e indique:

  • si acaso el triángulo es inválido; y
  • si no lo es, qué tipo de triángulo es (escaleno, isósceles o equilátero).
Ingrese a: 3.9          Ingrese a: 2.0
Ingrese b: 6.0          Ingrese b: 1.9
Ingrese c: 1.2          Ingrese c: 2.0
No es un triangulo valido.   El triangulo es isosceles.
Ingrese a: 3.0          Ingrese a: 3.14
Ingrese b: 5.0          Ingrese b: 3.14
Ingrese c: 4.0          Ingrese c: 3.14
El triangulo es escaleno.    El triangulo es equilatero.
TipPista

La desigualdad triangular son tres condiciones a la vez (una por cada lado), unidas con and.

Para el tipo: equilátero = los tres iguales; isósceles = al menos dos iguales; escaleno = todos distintos. Ojo con el orden en que preguntas.

Solución 
a = float(input('Ingrese a: '))
b = float(input('Ingrese b: '))
c = float(input('Ingrese c: '))

valido = (a < b + c) and (b < a + c) and (c < a + b)

if not valido:
    print('No es un triangulo valido.')
elif a == b and b == c:
    print('El triangulo es equilatero.')
elif a == b or b == c or a == c:
    print('El triangulo es isosceles.')
else:
    print('El triangulo es escaleno.')
NotaComentario

El orden importa: si preguntáramos primero por isósceles, un triángulo equilátero (que también tiene dos lados iguales) sería clasificado como isósceles. La condición más restrictiva va primero.

Nótese también que valido se calcula como una variable booleana antes del if. Eso hace que la cascada se lea casi como el enunciado, y es exactamente la misma técnica del ruteo del ejercicio 9 (anioOk, mesOk, diaOk).

4.2 Ejercicio 16 — Tipo de triángulo según sus ángulos

Determina el tipo de triángulo según sus ángulos. Es necesario encontrar el lado más grande (que sería la hipotenusa) y verificar si cumple el teorema de Pitágoras:

  • Si \(a^2 + b^2 = c^2\), el triángulo es rectángulo.
  • Si \(a^2 + b^2 < c^2\), el triángulo es obtusángulo.
  • Si \(a^2 + b^2 > c^2\), el triángulo es acutángulo.

donde \(c\) es el lado mayor.

TipPista

Este ejercicio son dos problemas encadenados: primero identificar el lado mayor (ejercicio 13), y recién después comparar. Conviene reordenar los tres lados en variables auxiliares.

Solución 
a = float(input('Ingrese a: '))
b = float(input('Ingrese b: '))
c = float(input('Ingrese c: '))

# 1) identificar el lado mayor (hip) y los otros dos (l1, l2)
if a >= b and a >= c:
    hip, l1, l2 = a, b, c
elif b >= a and b >= c:
    hip, l1, l2 = b, a, c
else:
    hip, l1, l2 = c, a, b

# 2) clasificar
if l1**2 + l2**2 == hip**2:
    print('El triangulo es rectangulo.')
elif l1**2 + l2**2 < hip**2:
    print('El triangulo es obtusangulo.')
else:
    print('El triangulo es acutangulo.')
NotaComentario

La asignación múltiple hip, l1, l2 = a, b, c es cómoda, pero si aún no se ha visto en clase se puede escribir en tres líneas separadas; el algoritmo es idéntico.

Para el ejemplo clásico 3, 4, 5: el mayor es 5, y 9 + 16 == 25 → rectángulo. Con 3, 4, 6: 9 + 16 = 25 < 36 → obtusángulo. Con 3, 4, 4: 9 + 16 = 25 > 16 → acutángulo.

Se puede combinar con el ejercicio 15 pidiendo que primero valide la desigualdad triangular.

4.3 Ejercicio 17 — Pago de horas extra

Entradas: categoría del empleado (int) y número de horas extra trabajadas en una semana (int). Alternativamente, el número de horas totales trabajadas en la semana, descontando 44.

Reglas:

  • Se pagan máximo 10 horas extra.
  • Si el empleado tiene categoría 4 o superior, no tiene derecho al pago de horas extra.
  • El monto a pagar por hora depende de la categoría: Cat 1: 5000, Cat 2: 8000, Cat 3: 10000.

Escribe un programa que calcule el monto a pagar.

TipPista

Tres decisiones distintas, mejor tomadas por separado:

  1. ¿Tiene derecho a pago? (categoría)
  2. ¿Cuántas horas se pagan efectivamente? (tope de 10)
  3. ¿Cuánto vale la hora? (categoría)
Solución 
categoria = int(input('Categoría del empleado: '))
horas     = int(input('Horas extra trabajadas: '))

if categoria >= 4:
    print('Su categoría no tiene derecho al pago de horas extra.')
    monto = 0
else:
    # tope de 10 horas extra
    if horas > 10:
        horas_pagadas = 10
    else:
        horas_pagadas = horas

    # valor de la hora según categoría
    if categoria == 1:
        valor = 5000
    elif categoria == 2:
        valor = 8000
    else:            # categoría 3
        valor = 10000

    monto = horas_pagadas * valor
    print('Horas pagadas:', horas_pagadas)
    print('Monto a pagar:', monto)
NotaComentario y variante

Variante con las horas totales de la semana como entrada:

total = int(input('Horas totales trabajadas: '))
horas = total - 44
if horas < 0:
    horas = 0

Un buen tema de discusión: ¿qué pasa si la categoría ingresada es 0 o negativa? El enunciado no lo dice, y ese es justamente el punto — decidir explícitamente qué se considera entrada válida es parte del diseño del programa.

4.4 Ejercicio 18 — Llamadas telefónicas internacionales

El costo de las llamadas telefónicas internacionales depende de la zona geográfica en la que se encuentra el país de destino y del número de minutos que se hablaron. Además, las llamadas que se inician en horario nocturno tienen un descuento del 20 %.

Código de zona Zona Precio por minuto
12 América del Norte 2
15 América Central 2.2
18 América del Sur 4.5
19 Europa 3.5
23 Asia 6
25 África 6
29 Oceanía 5

Escribe un programa que lea como entrada la zona de una llamada, el horario (día o noche) y la cantidad de minutos, e indique el costo total de la llamada. Debe validarse que la zona, el horario y la cantidad de minutos sean válidos. De lo contrario, termina con error.

TipPista

Conviene resolverlo en dos etapas: primero obtener el precio por minuto (una cascada larga que además detecta la zona inválida), y luego validar horario y minutos antes de calcular.

Truco: inicializa precio = 0 y úsalo como marca de “zona inválida”.

Solución 
zona    = int(input('Código de zona: '))
horario = input('Horario (dia/noche): ')
minutos = int(input('Cantidad de minutos: '))

# --- precio por minuto según la zona ---
if zona == 12:
    precio = 2
elif zona == 15:
    precio = 2.2
elif zona == 18:
    precio = 4.5
elif zona == 19:
    precio = 3.5
elif zona == 23:
    precio = 6
elif zona == 25:
    precio = 6
elif zona == 29:
    precio = 5
else:
    precio = 0          # marca de zona inválida

# --- validaciones ---
zona_ok    = precio > 0
horario_ok = (horario == 'dia' or horario == 'noche')
minutos_ok = minutos > 0

if not zona_ok:
    print('Error: código de zona inválido.')
elif not horario_ok:
    print('Error: el horario debe ser dia o noche.')
elif not minutos_ok:
    print('Error: la cantidad de minutos debe ser positiva.')
else:
    costo = precio * minutos
    if horario == 'noche':
        costo = costo * 0.8      # 20% de descuento
    print('El costo total de la llamada es', round(costo, 2))
NotaComentario

Dos cosas para destacar en clase:

  1. Las zonas 23 y 25 comparten precio. Se pueden fusionar en una sola rama: elif zona == 23 or zona == 25:. Es una buena oportunidad para mostrar que la cascada agrupa casos, no valores.

  2. Reportar el error específico (elif not horario_ok) es más útil que un único “datos inválidos”. Y usar variables booleanas con nombre (zona_ok, horario_ok, minutos_ok) hace que el if final se lea solo.

Aplicar el descuento como costo * 0.8 es equivalente a costo - costo * 0.2; la primera forma es la que se usa habitualmente.

4.5 Ejercicio 19 — Tiro al blanco

En un juego de video hay que dispararle a un tablero de tiro al blanco formado por cuatro áreas cuadradas concéntricas separadas por una distancia \(d\) (igual para todas las áreas). El tablero está en un plano cartesiano de dos dimensiones cuyo centro \((0,0)\) es el centro mismo del blanco.

Si las áreas concéntricas se enumeran desde la más interna hasta la más externa de 1 a 4, realiza un programa que retorne el número del área en la cual ha caído el disparo. El usuario debe ingresar la distancia \(d\) y el punto \((x, y)\).

Ingrese distancia: 5     Ingrese distancia: 1
Ingrese x: 3             Ingrese x: 6
Ingrese y: 4             Ingrese y: 6
Area 1                   Fuera del area
TipPista

Las áreas son cuadrados, no círculos: lo que determina en qué anillo cae el punto no es la distancia euclidiana, sino \(\max(|x|, |y|)\).

Con eso, el punto está en el área 1 si \(\max(|x|,|y|) \le d\), en el área 2 si \(\le 2d\), y así.

Solución 
d = float(input('Ingrese distancia: '))
x = float(input('Ingrese x: '))
y = float(input('Ingrese y: '))

# el "radio" de un cuadrado centrado en el origen
lado = max(abs(x), abs(y))

if lado <= d:
    print('Area 1')
elif lado <= 2*d:
    print('Area 2')
elif lado <= 3*d:
    print('Area 3')
elif lado <= 4*d:
    print('Area 4')
else:
    print('Fuera del area')
NotaComentario

Verificación de los ejemplos:

  • d = 5, punto (3, 4): max(3, 4) = 4 <= 5 → Area 1. ✔ (Si las áreas fueran círculos, la distancia sería \(\sqrt{9+16} = 5\) — justo en el borde. Es un buen ejemplo para mostrar por qué la geometría del problema importa.)
  • d = 1, punto (6, 6): max(6, 6) = 6 > 4·1 = 4 → Fuera del area. ✔

Si max() aún no se ha visto, se reemplaza por:

if abs(x) > abs(y):
    lado = abs(x)
else:
    lado = abs(y)

que es, otra vez, el ejercicio 13 disfrazado.

5.1 Ejercicio 20 — Alfil y torre

Un tablero de ajedrez es una grilla de ocho filas y ocho columnas, numeradas de 1 a 8. Dos de las piezas del juego de ajedrez son el alfil y la torre. El alfil se desplaza en diagonal, mientras que la torre se desplaza horizontal o verticalmente. Una pieza puede ser capturada por otra si está en una casilla a la cual la otra puede desplazarse:

Escribe un programa que reciba como entrada las posiciones en el tablero de un alfil y de una torre, e indique cuál pieza captura a la otra:

Fila alfil: 7        Fila alfil: 3        Fila alfil: 3
Columna alfil: 6     Columna alfil: 4     Columna alfil: 3
Fila torre: 4        Fila torre: 7        Fila torre: 8
Columna torre: 3     Columna torre: 4     Columna torre: 5
Alfil captura       Torre captura        Ninguna captura

Supón que todos los datos ingresados son válidos.

TipPista
  • La torre captura si comparte fila o columna con el alfil.
  • El alfil captura si está en la misma diagonal: la diferencia de filas y la diferencia de columnas tienen el mismo valor absoluto.

Como el movimiento es simétrico, ¿pueden capturarse ambas a la vez? (No: una pieza no puede estar al mismo tiempo en la misma fila/columna y en la misma diagonal.)

Solución 
fa = int(input('Fila alfil: '))
ca = int(input('Columna alfil: '))
ft = int(input('Fila torre: '))
ct = int(input('Columna torre: '))

alfil_captura = abs(fa - ft) == abs(ca - ct)
torre_captura = (fa == ft) or (ca == ct)

if alfil_captura:
    print('Alfil captura')
elif torre_captura:
    print('Torre captura')
else:
    print('Ninguna captura')
NotaComentario

Verificación de los tres ejemplos:

Alfil Torre abs(Δfila) abs(Δcol) Resultado
(7, 6) (4, 3) 3 3 Alfil captura
(3, 4) (7, 4) 4 0 Torre captura (misma columna)
(3, 3) (8, 5) 5 2 Ninguna captura

El corazón del ejercicio es traducir “estar en la misma diagonal” a abs(fa - ft) == abs(ca - ct). Vale la pena dibujarlo en la pizarra: moverse una casilla en diagonal cambia fila y columna en la misma cantidad.

El abs() es imprescindible: sin él, solo se detectaría una de las dos diagonales.

5.2 Ejercicio 21 — El paracaidista de Kreisdorf

Para celebrar el aniversario de la fundación de Kreisdorf, la alcaldesa ha organizado un espectáculo aéreo que finalizará con el aterrizaje de un paracaidista en la plaza del pueblo.

La plaza es circular, y su radio es de 47 metros. En su centro hay una pileta de 7 metros de radio. Además, hay cuatro áreas verdes en las posiciones indicadas en la figura; los radios interno y externo de las áreas verdes son, respectivamente, 20 y 35 metros. El resto de la superficie es cemento.

El público que irá a presenciar el espectáculo se ubicará en el sector rayado de la figura (entre los 45° y los 90°).

El punto de aterrizaje está definido por dos valores: su distancia al centro de la plaza y el ángulo con respecto a las coordenadas indicadas en la figura.

Escribe un programa que, a partir de la distancia y el ángulo de aterrizaje, le indique al paracaidista dónde caerá. El programa debe imprimir PILETA, AREA VERDE, PUBLICO, CEMENTO o FUERA DE LA PLAZA. Si el paracaidista aterriza justo en la frontera entre dos regiones, elige cualquiera de ellas.

Distancia: 25.4      Distancia: 29.1      Distancia: 40
Angulo: 192.9        Angulo: 333.0        Angulo: 60
AREA VERDE           CEMENTO              PUBLICO

5.2.1 21.a — Completar el código

Antes de escribirlo desde cero, completa el siguiente esqueleto de manera que produzca las salidas correctas:

d = float(input("Distancia: "))
a = float(input("Ángulo: "))

if  ________________________________ :
    print("Pileta")
elif ________________________________ :
    print("Público")
elif ________________________________________________________________ :
    print("Area verde")
else:
    print("Cemento")
TipPista

Las cuatro áreas verdes ocupan los sectores 0°–45°, 90°–135°, 180°–225° y 270°–315°, siempre entre los radios 20 y 35.

¿Notas el patrón? Los cuatro sectores se repiten cada 90°. Eso permite escribir la condición angular de las áreas verdes en una sola comparación, usando el operador %.

Solución 21.a — esqueleto completado 
d = float(input("Distancia: "))
a = float(input("Ángulo: "))

if d <= 7:
    print("Pileta")
elif 45 <= a <= 90:
    print("Público")
elif 20 <= d <= 35 and (a <= 45 or 90 <= a <= 135 or 180 <= a <= 225 or 270 <= a <= 315):
    print("Area verde")
else:
    print("Cemento")
Solución 21.b — programa completo 
d = float(input("Distancia: "))
a = float(input("Ángulo: "))

if d > 47:
    print("FUERA DE LA PLAZA")
elif d <= 7:
    print("PILETA")
elif 45 <= a <= 90:
    print("PUBLICO")
elif 20 <= d <= 35 and a % 90 <= 45:
    print("AREA VERDE")
else:
    print("CEMENTO")
NotaComentario

El orden de la cascada es todo. Las regiones se solapan si se las mira por separado, así que la cascada resuelve las prioridades: primero lo que está fuera, luego la pileta (que es el centro y no depende del ángulo), luego el público (que va desde la pileta hasta el borde, sin importar el radio), y recién al final las áreas verdes.

El truco del %: las cuatro áreas verdes se repiten cada 90°, ocupando la primera mitad de cada bloque. Entonces a % 90 <= 45 cubre de una sola vez los cuatro sectores 0°–45°, 90°–135°, 180°–225° y 270°–315°. La versión larga con cuatro or es igual de correcta; conviene mostrar las dos y comparar.

Verificación de los ejemplos:

Distancia Ángulo a % 90 Resultado
25.4 192.9 12.9 ≤ 45, y 20 ≤ 25.4 ≤ 35 AREA VERDE ✔
29.1 333.0 63.0 > 45 CEMENTO ✔
40 60 — PUBLICO (45 ≤ 60 ≤ 90) ✔

Nótese que el tercer caso tiene d = 40, fuera del rango de las áreas verdes, pero eso da lo mismo: la rama del público se evaluó antes y no mira la distancia.

6 Para cerrar

Los patrones que se repitieron a lo largo de toda la guía:

  1. Validar primero. La entrada inválida se descarta al inicio de la cascada; así el resto de las condiciones quedan simples (ejercicios 10, 12, 18).
  2. La condición más restrictiva va primero. Equilátero antes que isósceles, pileta antes que cemento (ejercicios 15, 21).
  3. Nombrar las condiciones. Guardar el resultado de una expresión lógica en una variable con nombre (diaOk, valido, alfil_captura) convierte un if ilegible en uno que se lee solo (ejercicios 9, 15, 20).
  4. Calcular antes de decidir. necesarias = 3 * capibaras, lado = max(abs(x), abs(y)): el cálculo va fuera del if, no repetido dentro de cada rama (ejercicios 11, 19).
  5. if-elif-else cuando las alternativas son excluyentes. No es solo más corto que varios if sueltos: es mucho más difícil de equivocar (ejercicio 8).
